## Layout

- `metrics.plugin.*.svg`: generated by `.github/workflows/metrics.yml` (manual dispatch only, needs the `METRICS_TOKEN` secret). Never hand-edit them.

## Verify

No build. Before a commit, run `gitleaks git --redact --no-banner` and check that every image and link in `README.md` resolves.

- The bio is first person and must match the canonical copy (`Rethunk-Tech/internal`, `internal-copy` skill); titles and company names are not paraphrased.
- Every claim in the README is checkable: repos linked under "In the open" exist and are public.
- Workflow actions stay pinned to a full commit SHA.
